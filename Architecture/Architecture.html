Các luồng demo

A. Dữ liệu vườn lên dashboard

T02 → T06 → T08 → T15 → T11
  1. Node 1 đọc SHT20 qua Modbus RS485 và độ ẩm đất mỗi 10 giây.
  2. Gửi gói ESP-NOW (có seq, CRC) tới Bridge.
  3. Bridge in một dòng JSON qua USB Serial.
  4. Gateway gửi v1/gateway/telemetry dưới tên Node1-Garden.

B. Tự tưới khi đất khô

T12 → T13 → T15 → T08 → T06
  1. Độ ẩm đất < soil_min: RuleChain tạo alarm và gửi email.
  2. RuleChain gửi RPC setPump cho Node1-Garden.
  3. RPC đi qua v1/gateway/rpc tới Gateway, rồi xuống Bridge.
  4. Bridge gửi ESP-NOW, Node 1 bật relay bơm và báo lại.

C. Tự bật quạt khi nóng

T02 → T12 → T11
  1. Nhiệt độ từ SHT20 của Node1-Garden vào RuleChain.
  2. Nhiệt độ > temp_max: đổi originator theo relation sang Node2-Control.
  3. Gửi RPC setFan, Node 2 bật quạt. Người dùng cũng bật tắt quạt, đèn trên dashboard.

D. Mất Internet rồi có lại

T15
  1. Gateway mất kết nối, lưu dữ liệu vào SQLite.
  2. Có mạng lại: gửi bù kèm ts gốc.
  3. Biểu đồ trên CoreIOT không bị đứt đoạn.

E. Cập nhật firmware OTA

T14
  1. Upload .bin v1.1, gán cho Node 2.
  2. Node 2 nhận fw_version mới, tải và kiểm checksum.
  3. Khởi động lại, báo fw_state = UPDATED.

F. Ghi nhận sự kiện

N06
  1. Web app nhận telemetry qua WebSocket API của CoreIOT.
  2. Phát hiện sự kiện: bơm bật/tắt, vượt ngưỡng, node mất kết nối.
  3. Ghi vào SQLite, hiển thị dòng thời gian và lọc theo ngày.
